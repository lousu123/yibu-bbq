1现状判断 · 你不是从零开始，是从"负数"开始

新店是从 0 开始，你是从"顾客点进来看到 0 评价、关掉页面"开始。这比新店更难，但有一个好处：你已经有真实客人，只是没把他们变成资产。

三个必须承认的事实：

  • 线上不存在：没评价、没星级、没图片，等于把搜附近的客人全部让给对手
  • 老客没沉淀：来吃过的人，你既不知道是谁，也唤不回来
  • 招牌没被说出来："新疆"这两个字是最值钱的，但现在没人知道这家是新疆人开的
核心策略：先补"存在感"（点评从 0 到 50 条），再补"连接"（把到店客人装进微信），最后才是拉新。顺序不能反。

3产品 · 把"新疆"变成能点的菜

"新疆人开的烧烤店"这句话，顾客在店里看不到，得靠菜单和话术讲出来。

三个招牌，必须天天有、天天推：

  • 红柳羊肉串：最直观的新疆符号，做引流款，定 5–6 元/串
  • 馕坑肉 / 烤包子：别人没有的品，做记忆点，让顾客拍照
  • 大盘鸡：适合 3–4 人，拉客单，做套餐主角

搭配三样，决定客单和毛利：

  • 馕（当主食，也可以夹串吃）、新疆酸奶、格瓦斯/咸奶茶
  • 这几样成本低、毛利高，且别人家没有
别做的：为了"丰富"上几十个 SKU。烤串店最怕备料太多、翻台太慢。招牌留 3 个、搭配留 5 个，够了。
4线上从 0 补 · 前 50 条评价是第一优先级

这家店现在最值钱的动作，不是发传单，是把已经来过的客人变成评价。

  • 门店页先补全：招牌菜图、营业时间、电话、地址写到门牌号；头图放"炭火现烤的串"，不要放门头照
  • 评价机制：结账时说一句"帮我们写两句，下次来送一串"；扫码点餐页挂评价入口
  • 节奏：每天稳 3–5 条，不要一天刷 30 条，容易触发平台风控
  • 差评：当天回复、当天改。烤串店的差评集中在"凉了""等太久""串小"，回复里直接说怎么改
关键：这家店已经有真实客人（日均还有流水），所以不需要刷单，只需要把"请评价"变成结账的标准动作。一段话术、一个赠品，就能把评价攒起来。
5外卖 · 烤串是能送的，但要解决"凉"
  • 能送：烤串锡纸包 + 保温袋，30 分钟内送到，口感损失可控
  • 不能送：大盘鸡这类汤菜（撒汤）、现烤现吃的脆皮类
  • 套餐化：只推套餐（20 串 + 馕 + 酸奶），不卖单品，单品配送费占比太高
  • 目标占比 35–40%：烤串比正餐更适合外卖，但别超过堂食，堂食才是体验

包装和温度是差评源，保温袋该花就花，一串凉的羊肉串能毁掉十条好评。

6私域 · 把线下的老客捡回来

这家店现在最大的浪费是：来过的人，一个都没留下。

  • 扫码点餐即入会：送一串或一份小菜，成本几块钱，换来一个可触达的客人
  • 建群：按小区建，一个群 100–200 人。群里每周发一次"今日现串"，不要天天发广告
  • 储值：首充 200 送 20，烤串店一次聚餐就能用完，门槛不高
  • 固定日：周三"串日"，群内每人多送两串，制造固定到店节奏
顺序很重要：先把老客捡回来（成本最低），再谈拉新。这家店日均流水不到 1 千，说明老客还有，只是没被唤醒。
7内容 · 年轻新疆老板，本身就是最好的素材

很多店做内容要编故事，你不用。三个天然选题：

  • 「新疆人烤的串」：现串、撒孜然、炭火翻面，15 秒就能拍出食欲
  • 「一天的备料」：早上几点起来穿串、一天穿多少串，真实感最抓人
  • 「馕怎么吃」：夹串、泡酸奶，教顾客一种吃法，比说好吃有用

抖音发同城、小红书发图文，每周 2 条。先做 20 条再谈投流——内容跑不动，投流只是买热闹。

不要一上来就投流、搞大促。这家店现在的问题是"没被看见"，不是"没人来"。投流之前，先让点进来的人看到 50 条真实评价。
9营收目标 · 从 1 千到 2 千，怎么走

现在日均不到 1 千元，按人均 50 算，一天大约 15–20 位客人。这个量级说明基本盘还在，只是没增长引擎。

时间目标日均靠什么
第 1 个月1200–1500评价与门店页补全，自然搜索开始带来新客
第 2 个月1800–2200外卖上线 + 微信群老客回流
第 3 个月2500–3000固定日 + 内容带来的稳定新客

这是按人均 50、逐步恢复测算的路径参考，不是承诺。真实数字要看门店位置、周边人流和出品稳定性。

10收银系统 · 老店最该补的四件事
  • 扫码点餐：减少点单错误，也顺带把客人变成会员
  • 买单同步点评：这是从 0 评价到 50 条评价最快的通道
  • 会员储值：烤串店复购高，储值是最有效的锁客
  • 成本卡：串类成本必须算清，不然卖得越多亏得越多

12先说清楚一张表 · 这店现在值不值得签

这家店在海鸥里没有归属人，带着「淘金」标签，属于需要走分配路径的门店。签之前建议先做三件事：

  • 确认作业权限：淘金门店要走分配流程，别做完了才发现进不去
  • 线下先看一次：日均流水不到 1 千，要确认是"没做线上"还是"产品本身有问题"，这决定后面的动作
  • 和老板对齐预期：他现在最想解决的是"没人来"，方案要能回答这一句，而不是讲一堆系统功能
提醒：如果线下看店发现出品或位置有硬伤，线上做得再好也只是把客人骗来一次。这种店要先修产品，再谈运营。
13下一步 · 本周先做三件事
  • 把门店页补全：招牌菜图、营业时间、电话，先把"线上存在感"建立起来
  • 把"请评价"变成话术：写在一张纸上贴收银台，老板和店员照念
  • 把二维码摆出来：桌卡 + 收银台，扫码点餐即入会送一串

最后一句：这家店不需要变成网红店，只需要让住在黄岩里周边的人知道——想吃串，拐个弯，新疆人开的那家，肉是现穿的。
